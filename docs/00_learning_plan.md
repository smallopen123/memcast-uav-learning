# 逐步实践计划

> 如果你想直接按页面逐课操作，请从 [第 0 步：安装并验证环境](../tutorial/00_setup.md) 开始，或打开 [可点击式教程总目录](../tutorial/README.md)。

不要先通读全部源码。每次只完成一节课，并用“输入—变换—输出—约束—测试”五个问题解释代码。

## 每节课的固定动作

1. 先直接运行课程，保存输出；
2. 在入口 `main()` 打断点；
3. 使用“步入”进入一个核心函数；
4. 记录数组的形状、单位和索引范围；
5. 完成课程末尾的实践注释；
6. 运行 `python -m pytest -q`，确认修改没有破坏其他模块；
7. 用自己的话写一段不超过200字的解释。

## 八次学习任务

### 第1次：窗口与无泄漏划分

- 文件：`lessons/lesson_01_windowing.py`
- 要解释：为什么历史切片右端不包含？为什么测试历史可以包含划分点之前的观测？
- 验收：能够手算第一个测试窗口的四个索引。

### 第2次：无人机运动学特征

- 文件：`lessons/lesson_02_features.py`
- 要解释：位置如何通过一次差分得到速度、二次差分得到加速度？
- 验收：为每个特征标明单位。

### 第3次：组合检索

- 文件：`lessons/lesson_03_retrieval.py`
- 要解释：余弦相似度与DTW分别解决什么问题？
- 验收：分别设置 `alpha=0`、`alpha=1`，解释排名变化。

### 第4次：经验记忆

- 文件：`lessons/lesson_04_memory.py`
- 要解释：记忆为什么既要保存原始历史，也要保存特征和未来位移？
- 验收：添加一个环境上下文字段，并增加测试。

### 第5次：反思层

- 文件：`lessons/lesson_05_reflection.py`
- 要解释：约束检查与轨迹修正为什么必须分开？
- 验收：实现一个简单圆形禁飞区检查。

### 第6次：动态置信度

- 文件：`lessons/lesson_06_confidence.py`
- 要解释：为什么不能在预测区间结束前使用真实误差？
- 验收：失败案例不增加置信度，且事件只能应用一次。

### 第7次：端到端实验

- 文件：`lessons/lesson_07_end_to_end.py`
- 要解释：最终指标为什么必须与简单基线一起报告？
- 验收：改变一个参数，只分析一个变量，记录对MSE和检索结果的影响。

### 第8次：意图条件预测

- 文件：`lessons/lesson_08_intent.py`
- 要解释：任务规划意图、控制意图、从轨迹识别的意图有什么区别？
- 验收：设计两级标签，例如 `mission=inspection`、`maneuver=turn_left`。

## 推荐提交节奏

每完成一节创建一个Git提交，例如：

```bash
git add lessons src tests docs
git commit -m "learn: complete lesson 01 windowing"
```

不要把八节课的所有个人修改一次性放进同一个提交。小提交更容易回退和比较。
