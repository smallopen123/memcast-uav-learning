# 真实无人机数据适配指南

## 推荐的统一数据格式

每条飞行至少转换为：

```text
flight_id,timestamp,x,y,z,vx,vy,vz,yaw,intent
```

其中：

- `x,y,z` 使用统一的局部坐标系，例如ENU；
- 时间戳必须单调递增；
- 位置单位统一为米，速度为米/秒，角度统一为弧度；
- `intent` 必须说明来源：任务规划、飞控指令、人工标注或在线识别器。

## 适配步骤

1. 按 `flight_id` 分组，绝不能跨飞行拼接窗口；
2. 检查时间戳重复、缺失和跳变；
3. 坐标转换后再重采样到统一频率；
4. 只用训练飞行估计归一化参数；
5. 按完整飞行划分训练/验证/测试，避免同一次飞行同时出现在两边；
6. 从训练飞行建立记忆；
7. 测试阶段只使用预测时刻已经可见的信息；
8. 同时报告恒速、恒加速度、卡尔曼滤波等确定性基线。

## 数据集差异

- DJI Matrice 100：重点处理飞控日志、坐标转换、IMU/GPS频率对齐；
- UZH-FPV：高速机动明显，视觉里程计与真值坐标需要对齐；
- NeuroBEM：适合研究动力学和气动效应，但字段与轨迹预测任务需重新映射；
- IDF-DS：固定翼约束与多旋翼不同，必须替换速度、转弯半径和爬升约束。

## 意图标签建议

可以采用两级标签：

```text
mission_intent: inspection / delivery / tracking / return_home
maneuver_intent: cruise / turn_left / turn_right / climb / descend / hover / land
```

训练意图识别器时，必须确保它只读取预测时刻之前的数据。若意图来自预先给定的任务规划，则可以作为已知未来上下文，但需要在论文中明确说明。

## 约束不是通用常数

教学代码中的约束只为演示。真实实验必须根据：

- 机型；
- 载荷；
- 控制模式；
- 风场；
- 法规与空域；
- 数据中实际采样频率；

重新确定，并记录来源。不能把Matrice 100的约束直接用于固定翼。
