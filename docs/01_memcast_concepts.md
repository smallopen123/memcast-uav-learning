# MemCast概念与本教学实现

## 1. 经验积累

传统预测器往往把每个样本视为独立任务。经验记忆会保存：

- 历史轨迹；
- 历史运动学特征；
- 当时的意图与上下文；
- 随后真实发生的未来轨迹；
- 使用过的策略；
- 该经验在后续预测中的动态置信度。

教学代码位于 `src/memcast_uav/memory.py`。

## 2. 条件检索

仅比较统计特征可能忽略轨迹形状；仅比较DTW又可能忽略更抽象的运动状态。因此组合：

```text
feature cosine similarity
+ trajectory DTW similarity
+ memory confidence
+ intent match
```

教学代码位于 `src/memcast_uav/retrieval.py`。

## 3. 多候选探索

一个查询不直接产生唯一答案，而是从若干相似经验以及简单运动模型生成多个候选。这样可以保留多模态未来，例如路口处同时存在左转、右转和直行可能。

教学代码位于 `src/memcast_uav/pipeline.py::predict_window`。

## 4. 规律反思

反思不是一句“请检查结果”的提示词，而应包含可执行检查：

- 速度上限；
- 加速度上限；
- 高度范围；
- 转弯率上限；
- 后续可加入禁飞区、地形、能量和机型包线。

教学代码位于 `src/memcast_uav/reflection.py`。

## 5. 动态置信度

当一个预测完整结束、真实未来已经可见时，才比较预测器与基线。如果经验帮助预测器优于基线，再提高相关记忆的置信度。

教学代码位于 `src/memcast_uav/confidence.py`。其中 `available_at` 是防止未来信息泄漏的关键。

## 6. 教学实现与论文实验的边界

本仓库刻意使用确定性合成轨迹和规则候选，以便学习每个变量。它没有：

- 复现论文GPT-5提示词和随机采样；
- 复现论文ETTh数值；
- 声称这些飞行约束就是某一具体机型的真实飞行包线；
- 用三条或十条样本替代完整统计实验。

完成教学后，应在独立实验分支接入真实数据、确定性基线、消融实验和足够测试样本。
